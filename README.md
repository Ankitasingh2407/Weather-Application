# Weather-Application
 This is a simple weather app built using HTML, CSS, and JavaScript.
It fetches real-time weather data from the OpenWeatherMap API and displays key weather information based on the searched city.

 ## Features
   **Temperature** (in Celsius), 
   **Weather Condition** (e.g., Clear, Rainy, Cloudy),
   **Humidity** (in %),
   **Wind Speed** (in km/h),
   **Dynamic Weather Image/Icon** based on condition

  ## Technologies Used
    **HTML, CSS** – for responsive and clean user interface, 
    **JavaScript Fetch API** – to fetch real-time data from OpenWeatherMap API.
